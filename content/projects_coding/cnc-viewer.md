## Problem Statement

City Nature Challenge is an annual event that asks people around the world to document the nature around them using iNaturalist. Since CNC is a global event, it is a good way to highlight how biodiversity changes from place to place. However, that information is not easily accessed on iNaturalist or CNC websites.

## Project Details

City Nature Challenge Viewer is a open-source website that displays the species with the most observations for each CNC project. By showing the top species for each project, I hope people can appreciate the biodiversity represented by each place.
